# Sim2Real 部署流程网站

🌐 **[点击访问网站](https://1bhysy.github.io/ZBOT_Deploy_Example/)**

本网站介绍从 Mjlab / Isaac Lab 策略到实机部署的流程，并提供 `deploy_example` 框架示例下载。网站无需 ChatGPT 账号。

## GitHub Pages 发布

将本压缩包内的 `index.html`、`.nojekyll`、`README.md` 和 `downloads/` 上传到 `ZBOT_Deploy_Example` 仓库根目录。在仓库 Settings → Pages 中选择 Deploy from a branch，分支 `main`，文件夹 `/ (root)`。发布成功后，上面的链接即可访问。

页面的自定义 Tips 保存在访问者各自浏览器的 localStorage 中，不会同步到 GitHub。
